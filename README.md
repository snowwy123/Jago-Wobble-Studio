# Jago Wobble 1.8.0

Draw, wobble and animate. A free drawing studio for lively illustrations and frame-by-frame loops.

This repository contains the application source, examples, licence notices and illustrated guide. See **DEVELOPING.md** to build it. Ready-to-use Windows downloads belong under GitHub Releases.

## Get started

Read **Documentation/Jago-Wobble-Guide.pdf** for an illustrated introduction. The app’s **?** menu provides help and shortcuts. Start with a blank project or explore the editable examples. Save your editable project as well as any finished exports. Each studio works independently; Workscape is optional.
