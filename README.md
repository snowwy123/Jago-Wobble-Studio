# Jago Wobble Studio

**A little drawing studio for things that won't sit still.**

Hello! I made Jago Wobble Studio for sketching, playing with textures and turning little drawings into animated loops. Draw smooth lines or pixel art, make your own stamps, and give your artwork a bit of wobble.

**Open source. Free forever. No locked tools.**

## Start drawing

Extract the ZIP, then open **Jago-Wobble-Studio.exe** on Windows or **Jago-Wobble-Studio.html** in your browser. The browser version works offline too. The Windows app needs Microsoft WebView2 Runtime. If Windows blocks the unsigned app, use the HTML version.

Try an example from **Help (?)**, or start with a blank canvas. Use **Save** to keep an editable **.jago** file. Export a GIF to share your loop, or use PNG, a sprite sheet or PNG frames for other animation software.

## Have a play

- Draw with pens, pencil, spray, shapes and textured stamps. Import images or make your own brush pack.
- Add movement to strokes and layers, or build an animation frame by frame with onion skin and holds.
- Pick colours from the little wheel while you draw. Use Hex or RGB for an exact colour, and enlarge the picker whenever you like.
- Work with selections, layers, clipping, shading, symmetry and adjustable drawing guides.
- Try smooth drawing, chunky pixel looks or a true pixel art canvas. Choose your pixel size when starting or exporting.
- Click the paper dimensions above the canvas to resize it across every frame. Your marks keep their size, layers and motion. Undo restores the previous page.
- Make yourself comfortable with five colour themes, including Sketchbook and Candy Cloud.

## Take it to the print table

**Wobble → Dither:** export a **PNG sequence ZIP**, then in Jago Dither Studio choose **Layers → + Wobble loop**. Add dither textures, printing inks and lettering to your animated drawing.

**Dither → Wobble:** export a **Wobble project** from Dither and open the **.jago** file here. Choose a single printed layer or separate ink layers, then add a drawing layer above it. Keep your original **.jagodither** project to edit its text, images and print settings.

Dither accepts loops up to 12 seconds. The return trip supports up to 48 frames; choose a lower transfer rate for longer loops. These transfers use rendered frames, so keep the original project from each studio for full editing.
