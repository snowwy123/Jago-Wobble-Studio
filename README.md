# Jago Wobble

Draw something with a bit of life in it.

Draw with pens, shapes and stamp brushes, then animate the drawing frame by frame or add a little motion to a layer. Try the Odd Little Marks brushes if you want something rougher or more playful.

## Give it a try

Install with Jago Suite, or extract the portable download and open **Jago-Wobble.exe**.

Open an example and play it. Change a few frames or try a motion on one layer. Save the editable drawing before exporting your animation.
