# Jago Wobble 1.9.0

A little life in every line.

Draw expressive illustrations and bring them to life with frame-by-frame animation or editable motion. Start with a blank page or an example and keep the original drawing editable.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Wobble-Studio/releases/latest)

## Get started

Download **Jago-Wobble-v1.9.0.zip**, right-click it and choose **Extract All**. Open **Jago-Wobble.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition. Open **Jago-Wobble.html** for offline browser use in current Edge or Chrome.

Windows requires 64-bit Windows and .NET Framework 4.8. Windows studio hosts require Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-Wobble-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- Pens, shapes, stamp brushes, colour, opacity, pixel treatments and optional thin-stroke correction.
- Layers, editable motion and traditional frame-by-frame animation.
- Blank/duplicated frames, adjustable holds, named clips and forward/reverse/ping-pong playback.
- Onion skin with neighbouring-frame, active-layer and loop-wrap controls.
- Pointer-centred zoom, middle-mouse pan, Fit and 1:1; project audio for preview.
- Explore four seeded motion directions with gentle, lively and texture families.
- Keep motion favourites in the preset library and protect selected settings.
- Select frame ranges or add frames to a selection; batch holds, reverse, duplicate, move and delete.
- Create named clips from selected frames and use Focus canvas.
- Layer-motion switching and restoration have been corrected; Odd Little Marks v1.5 remains compatible.
