# A few things to play with

Open the .jago files using **Open** in the app, or choose an example in **Help (?)**. GIFs and PNGs are previews.

- **Bouncing ball:** a little pencil ball travelling back and forth. Try changing the frame holds or using onion skin.
- **Motion study:** a swinging pendulum, rippling ribbon, fluttering line and breathing shadow. Pick a layer and use **Edit active layer settings** in Motion to see how it works.
- **Shading study:** a pencil ball with a cast shadow, hatching, stipple and highlights. Hide layers to see what each one adds.
- **Brush sampler:** twelve textured marks to try, from chalk to dither.
- **Shape sampler:** eight shapes with a bit of movement.
- **Line study:** the same idea drawn with pen, pencil, marker and spray.
- **Starter presets:** import the .jagopresets file in the preset library for ready-made brush and motion settings.

These are simple tool demonstrations. Change them, pull them apart, or use them to start something of your own.
